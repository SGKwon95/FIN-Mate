### 6. AI 관리 화면에 커스텀 트레이스 뷰어 추가

#### 배경
- Phoenix iframe은 cross-origin 제약으로 특정 화면만 임베드 불가
- Phoenix REST API를 서버에서 프록시해 원하는 데이터만 커스텀 UI로 표시하는 방식으로 변경

#### 구현 파일

| 파일 | 변경 내용 |
|------|-----------|
| `app/api/admin/ai/traces/route.ts` | 신규 — Phoenix `/v1/spans` + `/v1/span_annotations` 프록시 |
| `app/(main)/ai-admin/AiAdminClient.tsx` | Phoenix iframe 탭 → 커스텀 '트레이스' 탭으로 교체 |
| `app/api/chat/route.ts` | `retrieval.documents` OTel span 속성 추가 |

#### 트레이스 뷰어 기능
- 테이블: 질문, 전체/LLM/DB ms 레이턴시 breakdown, LLM-as-judge eval 점수 컬러 dot, 시각
- 행 펼치기: 검색된 청크(문서명 + 유사도 + 내용), LLM 프롬프트 메시지(role별 색상), eval 점수 상세
- "Phoenix 전체 보기 ↗" 외부 링크

#### 주요 기술 사항
- `formatDateTime` 수화(hydration) 불일치 수정: `toLocaleString('ko-KR')` → 수동 zero-pad 포맷
  - 서버(Node): `"PM 12:48"`, 클라이언트: `"오후 12:48"` 불일치 문제
- Phoenix API 버전 대응: `GET /v1/spans?project_name=…` 먼저 시도, 실패 시 `POST /v1/spans` body fallback
- `retrieval.documents` 속성을 chat route에서 수동으로 설정해야 Phoenix에 청크 정보 전달됨
